# Aplicativo de Estatística

## Descrição
O "Aplicativo de Estatística" é uma ferramenta interativa e intuitiva desenvolvida para facilitar cálculos estatísticos. Ele foi projetado para atender estudantes, professores e profissionais que necessitam realizar análises estatísticas de forma prática e eficiente. Com uma interface amigável e responsiva, o aplicativo oferece suporte a diversos métodos de cálculo e visualização de dados.

## Funcionalidades

### Tela Inicial
- **Seleção de Métodos**: Escolha entre diferentes métodos de cálculo estatístico, incluindo:
  - Agrupamento Discreto
  - Agrupamento por Classes
  - Variáveis Aleatórias Contínuas
  - Variáveis Aleatórias Discretas
  - Regressão Linear
- **Alternância de Tema**: Opção para alternar entre os modos claro e escuro, garantindo conforto visual.

### Agrupamento Discreto
- **Entrada de Dados**: Permite inserir dados manualmente ou carregar arquivos CSV.
- **Tabela de Frequência**: Identificação automática de tabelas de frequência.
- **Cálculos Estatísticos**: Geração de medidas como média, mediana, moda, variância e desvio padrão.

### Agrupamento por Classes
- **Configuração de Classes**: Escolha o número de classes para análise.
- **Importação de Dados**: Suporte para importação de tabelas via CSV ou entrada manual.
- **Cálculos Avançados**: Determinação de amplitude, ponto médio e outras métricas.

### Variáveis Aleatórias
- **Distribuições Contínuas**: Cálculos para distribuições normais, exponenciais e uniformes.
- **Distribuições Discretas**: Suporte para distribuições binomial e de Poisson.

### Regressão Linear
- **Análise de Dados**: Insira pares de valores (X e Y) para calcular a equação da reta de regressão.
- **Visualização Gráfica**: Geração de gráficos de dispersão para análise visual.

### Visualização de Resultados
- **Gráficos Interativos**: Utilização da biblioteca Chart.js para exibição de gráficos dinâmicos.
- **Tabelas Dinâmicas**: Apresentação de dados organizados e fáceis de interpretar.

## Tecnologias Utilizadas
- **HTML5**: Estrutura semântica e responsiva.
- **CSS3**: Estilização moderna com suporte a temas claro e escuro.
- **JavaScript**: Lógica de interação e manipulação de dados.
- **Chart.js**: Biblioteca para criação de gráficos interativos.

## Como Usar
1. Clone este repositório ou faça o download dos arquivos.
2. Abra o arquivo `index.html` em um navegador web.
3. Escolha o método de cálculo desejado na tela inicial.
4. Insira os dados conforme solicitado.
5. Clique no botão "Processar" para visualizar os resultados.
6. Navegue pelas abas para explorar diferentes análises e gráficos.
