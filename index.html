Valor de Z (Z-Score)

O valor de Z calculado com base nos seus dados de amostra.

1º Caso: P(z >= a) = P(z < a)

2º Caso: P(z <= a) = P(z < a)

3º Caso: P(a < z <= b) = P(a < z < b)

4º Caso: P(z <= -a)

5º Caso: P(z > -a) = P(z >= -a)

6º Caso: P(-a < z <= b) = P(-a < z < b)

7º Caso: P(-a < z < b) = P(-a < z < b)

Valores representam a área à esquerda (probabilidade acumulada) do valor Z.
